# NUIST ACM 训练看板

教室大屏展示端，使用 GitHub Pages 发布。数据来自独立的
[训练数据仓库](https://github.com/ChenLingHan/nuist-acm-member-training-database)，每 30 秒检查更新。

累计榜、近七天、新生榜、通过动态依次轮播，自动切换到看板时显示首屏，不自动翻阅后续排名。
左右按钮与方向键翻阅当前榜单，顶部标签切换看板，空格暂停，右上角进入全屏。
页头南京信息工程大学校徽由用户提供的 xybs9.rar 中原版 AI 素材导出。
累计使用个人页总量与已收录去重题数的较大值，已知新题不被旧主页快照封顶；两者都未核对完整时标 +。
周榜统计北京时间今日及前六天当前已知的首次 AC，历史补采期间可能调整。
题号按洛谷难度 / CF 题目评分着色，QOJ 及未评分题保留灰色。

发布源为 main 分支根目录。此仓库只含静态展示代码，无后台、学号、账号表或登录凭据。
